# Dataset

The dataset used in this project is publicly available and was obtained from Kaggle.

Due to file size and repository management considerations, the raw dataset is not included in this repository.

Dataset source:

Kaggle — Bank Customer Segmentation Dataset

The analysis notebook contains the complete data preparation, cleaning, exploratory analysis, RFM analysis and K-Means segmentation workflow.

**Note:** This project uses publicly available data and does not represent confidential or proprietary banking data.
